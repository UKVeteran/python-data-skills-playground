# Python Data Skills Playground 🚀

An advanced, interactive browser-based learning and execution environment designed for intermediate-to-advanced data science practitioners and educators. Spanning a flexible 4–8 week curriculum, this platform combines structured data analysis tasks, automated data cleaning suites, interactive visualization workbenches, and a secure Python coding sandbox.

## Key Features
- **Curriculum Hub:** Structured 4–8 week learning roadmap from foundational pandas/NumPy operations to advanced exploratory data analysis and model deployment.
- **Dataset Hub & Cleaner:** Upload custom CSV files or load built-in benchmark datasets. Perform missing value imputation, outlier detection, dtype casting, and filtering with live previews.
- **Exploratory Visualisation Workbench:** Generate publication-ready Matplotlib, Seaborn, and Plotly charts (histograms, scatter plots, correlation heatmaps, boxplots).
- **Interactive Code Sandbox:** A sandboxed Python execution environment allowing users to write and execute custom pandas/NumPy/scikit-learn scripts with real-time dataframe inspection and output logging.
- **Guided Challenge Lab:** Step-by-step interactive coding exercises with automated verification checks.

## Quick Start
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```
